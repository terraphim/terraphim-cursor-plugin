This is a read-first setup command. Explain the [setup guide](../README.md) and
show a proposed per-entry configuration diff. Do not run installers, modify
files, start an MCP process, enable synthesis, capture memory or activate hooks
merely because this command was invoked.

1. Identify the installed editor, four original skills and pinned separate CLI/
   MCP dependencies. Native acceptance requires the matching release qualification
   record; source/examples are not proof. The whole update cannot publish until
   native hooks pass.
2. Ask which project, exported graph and corpus the user intends to use. Show
   existing project entries first. On a collision, stop and ask the user to
   select another entry name or reconcile it manually; never replace a whole
   configuration file or a global profile.
3. Explain that editor graph export is explicit, retrieval is the default, and
   synthesis shares retrieved passages with the configured model. Memory writes
   authored content to a separate store; changing cwd does not isolate it.
4. Keep hook activation, rewriting and receipt capture off. Automatic failure
   capture is unavailable until actual native result-shape qualification. Show
   inactive examples and each side effect before any separately requested setup.
5. For an authorised change, use only the reviewed entry-level plan. Rehash
   actual dependencies and config, retain before/after files, and verify saved
   results. Do not call a sample input or model summary a successful output.
6. Explain how to remove only owned entries and restart the relevant connection;
   preserve other settings, documents, graphs, memories and learnings.
