# Public setup inputs

These files are **inputs**, not outputs of a new Cursor session. Search only the
`corpus/` directory; `concepts/Risk.md` explains Logseq-compatible `synonyms::`
syntax and is deliberately outside that corpus. Create and export a fresh graph
through the editor for native acceptance. Do not substitute the existing sample
graph for newly produced output.

`compiled-corrections.json` preserves a real Clients 1.21.20 compiler output from
the prior public `printf` learning example. It is a harmless illustration of
`Thesaurus.data`/`display_value`, not the new Cursor `--chek` validator proof and
not an active rule. `guard-rules.json` is deliberately empty.

The role and settings `.example` files use illustrative absolute paths. The
policy's hashes match these exact example bytes. Replacing paths changes their
hashes: review and rehash the actual role/settings/rule files, update the policy,
then hash the complete policy and update the hook argument. Keep setup manual.
Use real owner-only directories, and retain an empty project `.terraphim`
discovery layer; never delete existing configuration to make an example fit.

See the [setup guide](../README.md) for versions, side effects and qualification.
